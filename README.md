# Портфолио различных файлов из Airflow
В данном репозитории представлены проекты, разработанные для работы с Apache Airflow. Основу составляют DAG-файлы, реализующие различные ETL-процессы, а также соответствующие SQL-запросы, которые вынесены в отдельную ветку sql для удобства управления версиями.
По сравнению с моими стандартными проектами, которые в 60% случаев ограничивались одним DAG-файлом, представленные здесь решения имеют более сложную структуру и включают несколько взаимосвязанных этапов обработки данных.
